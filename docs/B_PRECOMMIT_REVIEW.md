## 本轮发现并修复的问题

| 问题 | 原行为及影响 | 修复与验证 |
|---|---|---|
| 电池缓存缺少来源基线校验 | 修改 NPZ 容量后可生成新的哈希和原始实验来源声明，哈希链无法阻止错误归源 | 对实际使用的 8 个数组按名称/形状/固定 float64 编码计算固定摘要，绑定已核对提取；修改缓存、形状、循环标签或协议均拒绝 |
| 特殊 JSON 字符和数值造成 HTTP 500 | 孤立 surrogate、NaN、非法 ID 会进入错误响应或报告，序列化失败 | 请求进入 FastAPI 字段校验前检查有限 UTF-8 JSON；报告不回显非法 ID；非法 JSON 返回 400，结构错误返回 422 或检查拒绝报告 |
| 有限输入的计算结果溢出 | 极端 FE 差值可变成 Infinity，再使响应失败；极端分析数值也应有明确错误 | 对 FE 比值及一致性残差检查有限性；分析捕获数值溢出；新增端点与计算回归测试 |
| 隐藏 offer 泄露条件差异 | 即使目录项不可发现，互换候选仍返回双方温度是否不同 | 隐藏或无效 offer 的条件比较整体设为 null；匹配不返回畸形目录项 |
| 匹配输入的类型边界 | 超大整数可触发 OverflowError，布尔值可能被当成数值范围 | 范围严格要求有限数；异常目录数值作为未知条件处理 |
| 双向扫描混合拟合 | LSV 原表含正反扫描；混合所得斜率不同于任一单独分支 | 标明扫描结构并拒绝对未分支切片做 Tafel 拟合。默认稳态示例不受影响 |
| 拐点拟合坐标尺度不稳 | 极大周期跨度会使未经缩放的最小二乘矩阵失去稳定性 | 坐标归一化至 [0,1]，保留原周期标签，并限制精确整数范围；尺度不变性测试通过 |

这些修复不意味着可鉴定实验真实、保证化学安全或证明通用算法性能。报告中的 pass/warn/fail/not_checked 仍只覆盖实现的规则。

## 架构判断

保留当前组织：存储与授权由 A 统一维护，B 提供纯计算/检查函数、独立路由和导入适配，分析作为交付后可选工具。没有必要再建一套 B 的业务数据库。

以下事项在集成时必须处理：

1. A/C 使用新的 `CHECKS_PASSED / REVIEW_REQUIRED / REJECTED`，保留未知温度、FE、η 等缺失值；旧共享文档的 `FORMAL_PROOF_VALID` 不得直接映射为通过。
2. A 的 resolver 需要实际核验调用者、授权状态、版本与内容完整性。测试中的模拟 resolver 不能替代真实 ACL 和双签实现。
3. `load_slices` 依赖可信 manifest；它验证引用文件，不能独立认证 manifest、测量真实性或许可归属。
4. B 的 4 MiB 检查发生在请求体读取后；HTTP 传输大小、并发、速率限制和统一异常外壳由 A 配置。
5. 直接依赖版本已固定，干净环境可安装；完整传递依赖锁定及 Starlette/httpx 弃用提示可在 A 统一依赖时处理。
