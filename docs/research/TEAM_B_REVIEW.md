## 直接采纳的设计

- 以具体实验数据切片为交换单位，保留条件、来源和文件标识。
- 检查报告作为独立对象，供目录、审批卡和分析页面共同使用。
- Agent 提出交换方案，双方人类确认后再释放授权。
- 将科学检查与数值分析拆成 `physics_compiler.py` 和 `domain_analytics.py`；保留现有模块名，先实现有前提、可测试的规则。
- 在演示中安排两份正常数据和一份明确标记的合成故障输入，展示正常交付与异常处理。
- 按文件 Owner 协作：B 提出字段需求，由 A 修改 `models/schemas.py` 和 `API_CONTRACTS.md`。

## 最新工程文档的具体衔接

`c1f5508` 新增了 [API 契约](../API_CONTRACTS.md)、[后端架构](../BACKEND_ARCHITECTURE.md)、[科学规则](../PHYSICS_RULES.md)、前端架构和实施总纲。可采用其中的服务拆分、统一 JSON 响应、双 PI 分步签署以及显式 Mock 模式。下列冲突需要在实现前由相应 Owner 统一；“Frozen”标记不能消除文档之间的实际不一致。

| 位置 | 已发现的具体冲突 | 接口建议 |
|---|---|---|
| API 契约与后端路由说明 | 下载分别写为 `/slices/{id}/download` 与 `/slices/{id}`；双签分别写为 `/barter/{proposal_id}/dual-sign` 与 `/barter/dual-sign` | 建议采用 API 契约中的带 `/download` 和 `proposal_id` 的路径，由 A 统一其他引用，C 按同一路径联调 |

| 科学规则与后端架构 | FE 下限分别是 0% 和 95%；CE 上限分别是 100% 和 100.5%；阻抗阈值分别是 15 Ω 和 50 Ω；电位参比也未统一 | 由 B 解释适用条件并提供唯一规则配置，不让两个模块各自硬编码一份阈值 |

| 验证响应 | 总则写物理检查失败返回 400，示例却用 200 加 `valid=false`；二值字段不能说明未检查 | 区分请求格式错误与检查结果；保留逐规则状态及检查覆盖范围，顶层 `valid` 若保留需明确语义 |
| `AnalysisRequest` 与 API 契约 | 后端模型只给切片 ID 与分析名，API 文档尚未定义分析端点响应 | 补充版本、参数、获权主体上下文、错误语义和绘图数组，供 C 使用 |

新 README 已增加启动命令，但当前树中仍没有 `backend/`、`frontend/` 或实验切片；这些是目标启动步骤，不能作为运行通过的证据。README 的 MIT 标记也与根目录实际 Apache-2.0 `LICENSE` 不一致，应由维护者统一；本分支保留现有许可证和 SFM 的独立 MIT 声明。

新增文献中，[Raccuglia 等的失败实验研究](https://www.nature.com/articles/nature17439)值得采用：它展示了历史失败合成记录在特定反应预测中的用途，支持我们保留有效的未成功实验。它不验证所有领域的“90%”比例、基础大模型收益或金库商业机制。[Anantharaj 等的电催化评估综述](https://doi.org/10.1039/C7EE03457A)可作为逐条规则阅读的起点；目前核对了题录与摘要，尚不能将其作为文档中所有硬阈值的直接依据。

## 实现前需要修正的关键假设

| v4 内容 | 核对结果或实现缺口 | 建议处理 |
|---|---|---|
| 用 OC22 提取实验 NiFe-LDH LSV/Tafel 切片 | [OC22 原论文](https://arxiv.org/abs/2206.08917)描述的是氧化物体系 DFT 弛豫和能量等任务，不能直接提供所需实验曲线 | 保留为计算催化数据参考；另找有许可、原始电位与电流数据及条件说明的实验来源 |
| 电池逐循环汇总 CSV 计算 dQ/dV | 当前字段缺少循环内电压与容量采样；作者的 [Severson 数据说明](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation)明确区分 summary 和 cycle 数据 | 增加循环内文件或作者已有的派生 dQ/dV 数据；两种路径分别记录来源和处理方法 |
| 前 100 周切片展示第 680 周 knee | 切片没有覆盖该区间，不能把后期拐点当作本次直接拟合结果 | 完整轨迹上的估计需另行授权；预测必须单独定义方法和验证。首版可只展示覆盖范围内的容量曲线 |
| FE=108% 自动证明造假；FE 必须在 95%–100% | FE 的计算依赖产物定量、电量与不确定性；低 FE 也可能是有效但选择性差的实验 | 输出定量一致性异常与复核需求。对演示故障可按明确规则阻止上架，不把规则命中解释成造假结论 |
| R²≥0.98、iR 补偿≥85%、固定阻抗/SNR、容量单调性作为普适公理 | 文档没有给出这些阈值的适用实验条件或验证依据 | 将有依据的阈值放入可配置的实验协议；不适用或缺元数据时返回 `not_checked`。模型拟合不佳不等于原始实验无效 |
| RHE 列与带 pH 项的电位阈值混用 | 参比电极转换与电位量纲是不同问题；同为 V 并不代表使用同一参比 | 单独记录参比、校准偏置、温度、pH 与补偿约定；仅在条件齐备时归一化，检查是否重复转换 |
| 报告直接写 `FORMAL_PROOF_VALID` 或引用示例 Lean 定理名 | 当前主分支没有 Lean 证明文件或可运行后端，只有设计文档 | 使用 `rule_checks_completed` 等实际状态；形式化证明需要对应定义、假设、证明文件和验证命令 |

FE 测量依据：[Kempler 与 Nielander，Reliable reporting of Faradaic efficiencies for electrocatalysis research](https://doi.org/10.1038/s41467-023-36880-8)。检查记录应保留测量前提与异常原因，不能只保留一个总分。LSV 本身也不能补出未测量的产氧量或 FE。

安全筛查可保留“元数据命中规则后隔离并复核”的机制；词表或正则命中并不是全面危险性认定，未命中也不意味着不存在提示词注入。元数据作为不可信文本处理，不能直接变成 Agent 的高优先级指令或任意工具调用。

## 数据源优先级

| 数据源 | 与新版 B 的关系 | 当前证据与下一步 |
|---|---|---|
| [Severson 2019 作者论文](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)与[代码说明](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation) | 最贴近快充、早期循环和 dQ/dV 展示 | 论文为 124 个 LFP/石墨电芯；作者说明含循环内测量。[TRI 官方目录](https://data.matr.io/)标注该数据集 CC BY 4.0。尚未检查具体文件，电芯编号、协议、单位、筛选记录和文件级条款仍需保留 |
| [Imperial 2022](https://zenodo.org/records/7235858) | 多温度容量比较或电池演示备选 | 元数据与许可已核对；原始包尚未完整下载。老化与 RPT 温度必须分列，保留作者的异常记录 |
| [TRI OER catalysis ACE-I](https://data.matr.io/oer-catalysis/) | 新补充的实验催化候选 | 官方页标注 CC BY 4.0，描述成分与 3 mA/cm² 过电位。可优先评估成分—活性展示；尚无证据支持所需的完整 LSV、Tafel 或 FE，不能替代 η10 |
| [OC22](https://arxiv.org/abs/2206.08917) | 计算催化扩展 | 不满足当前实验曲线输入要求 |
| [OCx24](https://arxiv.org/abs/2411.11783) | 另一个实验催化线索 | 原论文摘要指向 HER 与 CO₂RR，不应因名称相似就当作 NiFe OER 数据；当前不作为直接替代 |

这里的新增条目来自新版提案的定向核对，不计入旧两轮搜索命中数。候选“优先”依据任务适配和来源清晰度，不代表完成文件质量验收。Severson 数据许可与其模型/处理代码许可分开处理；作者仓库页面可访问不等于已经核准复制所有代码。

## 给 A 的最小接口需求

以下是待写入 A 的契约的语义建议，不新增并行 Schema。

| 对象或调用 | B 需要的内容 |
|---|---|
| 切片输入 | `slice_id`、`version`、来源与许可、文件哈希、测量类型、单位、测试条件、选择范围 |
| 科学检查 | `verify(slice, rule_profile)` 返回检查项、规则版本、适用前提、观测值、状态和原因；缺少 FE 原始测量时不默认通过 |
| 获权数据 | A 提供 `get_verified_slice(actor, slice_id, version)` 一类服务；B 分析端不能绕过访问授权直接读全部数据 |
| 分析调用 | `analyze(verified_slice, method, parameters)` 返回数值、绘图数组、覆盖区间、输入哈希、方法版本和警告 |
| Agent 匹配 | 先做领域、字段、条件、权限等硬筛选，再说明排序理由；跨领域互换需求来自双方明确声明 |
| C 的呈现 | 分别展示 `pass/warn/fail/not_checked`；计算失败或数据不足返回原因，不画预设的成功曲线 |

电池至少区分两个测量表：逐循环汇总表支持容量衰减；循环内表包含电芯、循环、充放电阶段及电压—容量采样，才支持重新计算 dQ/dV。平滑、插值、微分方法及参数必须随分析记录保存。dQ/dV 或 knee 特征本身不直接等同于已经确定某一退化机理。

## B 接下来交付的顺序

1. 确认首个电池文件和催化候选能支持哪些实际分析，生成来源记录及字段映射。
2. 与 A 冻结切片、检查报告和分析响应；C 据此制作 Mock，而不是先固定 42.5 mV/dec 或第 680 周等结果。
3. 修订已有的 `docs/PHYSICS_RULES.md`，逐条补充前提、单位、输入、规则性质、输出和测试例，并与 A、C 同步阈值和状态。
4. 实现纯函数式检查与分析，再接 HTTP 接口；分别验证正常数据、未知条件、格式错误及合成故障。
5. 联调获权交付和来源追溯。公开原始数据仍保留原作者，演示实验室身份单独标记为模拟。

“10/90”比例、“零抢发风险”和“彻底消除模型偏差”目前不应写成经验证的结论。业务愿景可以保留为假设，比赛证据落在实际运行的检查、授权、交付与分析结果上。
