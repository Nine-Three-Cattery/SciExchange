## 科学与集成约定

检查通过表示满足已执行规则，不签发不存在的 Lean 证明。经验阈值属于可配置筛查规则；缺少测量或不满足前提时明确输出 `not_checked`。低 FE、容量恢复和拟合不佳不自动定义为造假。分析参数和覆盖区间随结果保存。

真实切片必须来自已核对文件；不按预设的 42.5 mV/dec 或 240 mV 反向生成并冒充实验。取得不了某个来源时，保留真实替代来源名称和限制。合成数据仅用来测试与展示异常分支。

本轮先交付可独立调用、可挂载的科学模块。最新核对的 A 分支 `a881e58` 已有根目录 `app/`、平台入口与共享 Schema；C 分支 `eff0050` 已有前端。B 使用边界解析与普通返回对象，尚待统一包路径、版本、检查报告和授权契约后集成，不建立第二套业务数据库或交易服务。
