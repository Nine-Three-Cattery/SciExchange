## 接口约定

沿用 A 的 SQLite 与不可变 slice_id：同一个 ID 不能换内容或版本；修订数据使用新 ID。新增 ScienceRecord 存版本、内容摘要和科学报告，ScienceAdmission 存独立签名准入证据，不修改现有表结构。

导入原始科学 payload，不向未知温度补值。演示所有者映射为本地 lab_catalysis / lab_battery，不代表来源作者或真实机构授权；原作者归属、CC-BY-4.0 与转换记录保留。导入不会自动批准交易。

`/compiler/verify` 对已导入科学数据运行 B 检查。`/compiler/review-challenge` 和 `/compiler/review` 由所属实验室 PI 签署准入，绑定版本、内容、规则及报告摘要；不把签名解释为科学真实性证明。双签互换和 SciCredit 授权继续由现有平台处理。

`/analysis` 兼容原端点外壳，对真实切片必须提供 version，使用 B 方法与参数；数据交付和分析读取同一份验证过摘要的 payload。catalog 返回可用方法，避免对循环摘要要求 dQ/dV 或对单次 Q(V) 要求膝点。
