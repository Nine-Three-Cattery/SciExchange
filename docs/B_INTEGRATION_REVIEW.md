## 边界

客户端会丢弃旧会话响应，但不能撤销已发送且可能已经被服务端处理的签署操作。切换身份不会撤销合法的服务端交易；需要时应重新读取当前状态并显式授权。

本轮没有改变科学算法、许可、模拟结算或真实性声明。检查通过和 PI 准入仍分别表达；本地演示结论不扩展为生产安全保证。
